What is Diálogo?

It is a programming environment for children over 10 (younger ones with an adult alongside). In Diálogo, programs are built from symbols the children draw themselves. The language rests on two relations between symbols, substitution and categorization, plus about ten combinators (push, pull, teleport, collide, wildcards, an evaluation viewer). With their own drawings and these predefined visual symbols, children build games, simulations and abstract symbolic models, such as numbers and addition from scratch.

Rules live on the same board as the game. A character can push a rule out of the way and change the program while it runs, so metaprogramming becomes something a child can see and touch. A step-by-step execution viewer shows which rule fired at each step, and doubles as the debugger.

🎮 For learners:

  • Build games from your own drawings
  • Give characters behavior by combining a few visual symbols
  • See, step by step, why the game does what it does
  • Make games that rewrite their own rules while you play

🏫 For teachers and researchers:

  • Declarative from the first session, with no syntax and no imperative prerequisite
  • Runs offline on modest hardware, with no account or server; projects are saved locally
  • Interface in ten languages; adding one more means translating a single text file
  • A sequence of seven activities delivered as videos addressed to the children, so the tool is easy to adopt

Step 3

🎓 A sequence of seven activities

Each activity introduces one abstraction mechanism through a playable artifact. Projects 1 to 5 build games; projects 6 and 7 move toward abstract symbolic models. Projects 1 to 3 form a self-contained introduction, with a playable game already in project 2.

The activities are videos addressed directly to the children. The videos are currently in Spanish; an English version is in preparation.

♟️ Project 1: Chess

Categorization, the first mechanism of abstraction. Build a board and pieces that capture each other, then replace case-by-case rules with rules over categories.
Watch on YouTube

🐍 Project 2: The Snake

Substitution, the second mechanism. A growing-body snake, removing duplicated code, and the execution viewer as a debugger.
Watch on YouTube

👻 Project 3: From Pac-Man to a research submarine

A classic that puts every combinator to work, then re-skinned into a new domain. Simple rules, surprising results.
Watch on YouTube

🧠 Project 4: Metaprogramming puzzles

What happens when a program modifies itself? A labyrinth whose rules can be pushed and pulled during play.
Watch on YouTube

🚀 Project 5: Space ships

Ideas from game development: event-driven rules, hidden objects, collisions and time control, all combined in one shooter.
Watch on YouTube

🔢 Project 6: My calculator

Recursion and abstract symbol manipulation. Numbers and addition built from scratch, with no game and no character. It starts out simple and ends up the most demanding of the seven.
Watch on YouTube

🏁 Project 7: Score and reuse

Modularity and reuse. Add a scoring system to an earlier game, with no variables at all.
Watch on YouTube
