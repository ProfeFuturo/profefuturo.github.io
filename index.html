Diálogo

A visual programming environment where children draw their own symbols

What is Diálogo?

Diálogo is a free programming environment for children (roughly ages 10 to 17; younger kids with an adult alongside) in which programs are built from symbols the children draw themselves, rather than from predefined blocks. The language rests on two relations between symbols, substitution and categorization, plus about ten visual combinators (push, pull, teleport, collide, wildcards, an evaluation viewer). From that small set, children build games, simulations and abstract symbolic models, such as numbers and addition from scratch.

Rules live on the same board as the game. A character can push a rule out of the way and change the program while it runs, so metaprogramming becomes something a child can see and touch. A step-by-step execution viewer shows which rule fired at each step, and doubles as the debugger.

🎮 For learners:

  • Build games from your own drawings
  • Give characters behavior by combining a handful of visual combinators
  • See, step by step, why the game does what it does
  • Make games that rewrite their own rules while you play

🏫 For teachers and researchers:

  • Declarative from the first session, with no syntax and no imperative prerequisite
  • Runs offline on modest hardware, with no account or server; projects are saved locally
  • Interface in English and Spanish; adding a language means translating one text file
  • A seven-session curriculum delivered as videos addressed to the children, so you can adopt it before mastering the paradigm

🎓 A free seven-session course

Each session introduces one abstraction mechanism through a playable artifact. Sessions 1 to 5 build games; sessions 6 and 7 move toward abstract symbolic models. Sessions 1 to 3 form a self-contained introduction, with a playable game already in session 2.

The lessons are videos addressed directly to the children, with project files to download and return. The videos are currently in Spanish; an English version is in preparation.

⚙️ Session 0: Installation

Install Diálogo on Windows, Mac or Linux and start exploring.

♟️ Session 1: Chess

Categorization, the first mechanism of abstraction. Build a board and pieces that capture each other, then replace case-by-case rules with rules over categories.

🐍 Session 2: The Snake

Substitution, the second mechanism. A growing-body snake, removing duplicated code, and the execution viewer as a debugger.

👻 Session 3: From Pac-Man to a research submarine

A classic that puts every combinator to work, then re-skinned into a new domain. Simple rules, surprising results.

🧠 Session 4: Metaprogramming puzzles

What happens when a program modifies itself? A labyrinth whose rules can be pushed and pulled during play.

🚀 Session 5: Space ships

Ideas from game development: event-driven rules, hidden objects, collisions and time control, all combined in one shooter.

🔢 Session 6: My calculator

Recursion and abstract symbol manipulation. Numbers and addition built from scratch, with no game and no character.

🏁 Session 7: Score and reuse

Modularity and reuse. Add a scoring system to an earlier game, with no variables at all.

🔬 For educators and researchers

Diálogo is developed at the University of Buenos Aires as a research project on declarative programming for children. Both the environment and the curriculum are released as artifacts for adoption and empirical study.

  • Programming with Drawings: A Declarative Visual Environment and Its Classroom Evolution

    Agustín R. Martínez. SIGCSE Technical Symposium 2027, Sacramento, California, February 2027. To appear.

    The environment's design, its evolution across an in-person workshop and an online course, and the seven-session sequence.

  • A Language Based on Two Relations between Symbols

    Agustín R. Martínez. Onward! 2022 (SPLASH), Auckland. ACM. doi:10.1145/3563835.3567660

    The conceptual foundation: substitution and categorization as the two relations from which the language is built.
